my ai slop dev playbook


note: this was written on 04/16/25, some things may be outdated.

- ask chatgpt to give u ideas/draft a project
- paste any other sources (tweets, websites, etc) that is similar to what you want
- give it all the context, dont even have to be legible sentences
- have it ask you 5-10 questions for clarity + more context
(more context = detailed prompts = higher quality outputs)
- ask it to write design docs, output prompts for both frontend and backend
- take both prompts and paste it in ai tools:
    1. backend - entirely w/ replit.app or call chatgpt to do it for you (for rapid dev/bug fixes use cursor)
    2. frontend - use lovable.dev. personally it gets the design pretty well
- once satisfied, give api route context to any ai and ask it to generate DETAILED api documentation
- based on the api documentation, ask ai to connect your frontend to backend
- test everything works, you are now ready to launch
